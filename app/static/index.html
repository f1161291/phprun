不填入口时自动识别：index.php/main.php/app.php · main.py/app.py · main.js/app.js，否则目录内唯一脚本。语言优先级 PHP > Python > Node；有 index.php（或 public/index.php）时自动按 Web 启动。
须在页首显示的端口段内；指定端口已被占用时启动会直接报错。Web 服务读 getenv("PORT")（PHP）或 os.environ["PORT"]（Python）即可拿到该端口。
脚本写死了监听端口（如 8766）又不想改脚本时填这里：面板把分配到的端口（如 8600）反代到 127.0.0.1:8766，外部只暴露 8600。
格式 分 时 日 月 周：如 */5 * * * * 每5分钟、0 8 * * * 每天8点、30 2 * * 0 每周日2:30。到点自动启动，正在运行则跳过。

约定

1. 每个任务启动时分配一个端口，通过环境变量 PORT / HOST 传入；PHP 里用 getenv("PORT") 读，Python 用 os.environ["PORT"]，Node 用 process.env.PORT。
2. 创建或编辑时可指定端口，留空按启动顺序自动分配；端口池耗尽先停旧任务，或在 compose 里扩大范围。
3. 批处理脚本忽略端口即可，跑完状态自动变 exited；Web 服务保持 running。
4. PHP 运行模式：auto 看有没有 index.php（含 public/）决定 Web/CLI；可强制 web（php -S，文档根优先 public/）或 cli（php 脚本.php）。
5. PHP 项目带 composer.json 时，启动前自动 composer install；运行报缺 vendor/autoload.php 或缺类时自动 composer install / composer require 并重启一次（日志有「自动装依赖」标记）。
6. Python 缺包同样自动 pip install；三种语言共用一套面板与端口池。
7. 入口文件识别顺序：自定义命令 > 指定入口 > 顶层惯用名（index.php/main.php/app.php · main.py · main.js）> 顶层唯一脚本 > 深层惯用名 > 全目录唯一脚本。
8. 填了 cron 定时 的任务到点自动启动（每分钟最多一次）；填了反代内部端口时把对外端口 TCP 转发到脚本自己监听的端口。
PHP Web 示例（有 index.php 即自动 php -S，无需改代码）：
<?php
header("Content-Type: text/plain; charset=utf-8");
$port = getenv("PORT") ?: "8600";
echo "hello from php, listen " . getenv("HOST") . ":$port\n";
echo "PHP " . PHP_VERSION . "\n";
PHP CLI 示例（单文件批处理，跑完自动 exited）：
<?php
for ($i = 1; $i <= 3; $i++) {
    echo "step $i / 3 ...\n";
    flush();
    sleep(1);
}
echo "done, port=" . (getenv("PORT") ?: "-") . "\n";
Python / Node 任务同理：os.environ["PORT"] / process.env.PORT，按扩展名自动选解释器。
